# 장중 시장 탐색

2026-11-17. 사용자가 최신 기사 목록보다 지금 살펴볼 테마와 종목을 근거와 함께 좁히는 제품을 요청했다. 첫 화면은 대상 선택, 종목 비교, 관련 기사 확인으로 제한한다. 기획과 구현 추적은 GitHub #17~23에 있다.

## 관측과 집계

기존 Npay 실측 시세와 SQLite를 재사용한다. 기사 이후 최초 관측 대비 변화와 최근 5분 변화는 다른 값이다. 최근 5분은 UTC 분 경계 T와 T-5분을 사용하며 각 기준 직전 30초의 마지막 거래만 허용한다. 실제 양 끝 시각을 반환한다. 같은 정규장 안에서 중간 관측 공백은 90초 이하여야 하고 관측의 공급자 장 상태가 OPEN이어야 한다. 정확한 300초 틱 수익률을 보장하는 자료가 아니다. 누락 구간을 보간하거나 이전 거래일 가격으로 채우지 않는다.

테마는 검토된 소속과 같은 시장에서 발행사별 한 증권을 집계한다. 전체 유효 기업의 동일가중 평균이며 상승 종목 평균과 다르다. 집단 후보는 2개 이상, 구성의 75% 이상 유효 관측이 필요하다. 국내 KODEX 200 ETF와 미국 SPY ETF는 명시적인 비교 대용이며 전체 시장 지수와 동일하지 않다.

## 선별과 출시 상태

초기 정책은 최근 5분 절대 변화 0.2% 이상, 비교 ETF와 차이 0.3%p 이상이다. 테마 후보는 관측 기업의 75%가 같은 방향이어야 한다. 차이의 절댓값 순으로 정렬하고 기존 선택과 구성 종목이 절반 넘게 겹치는 항목은 제외한다. 이 정책은 개발 시작 기준일 뿐 별도 기간 유용성을 입증하지 않았다. 고정 테마 가중치나 모델 점수는 없다.

별도 기간 선별 평가와 실제 사용자 과제가 끝나지 않았으므로 새 홈은 `/?market-preview=1`로 확인한다. 기존 홈은 유지한다. 실제 관측 자료가 없으면 후보를 만들지 않는다. 거래량 비교는 충분한 동시간대 이력이 없어 미구현이며 거래 증가 또는 순매수 이유를 생성하지 않는다.

관련 뉴스는 현재 조회된 기사 집합과 종목 코드를 대조한다. 동일 원문 주소만 중복 제거하며 정정 기사는 유지한다. 전체 보관 기사 관계 역색인은 아직 없으므로 최근 조회 밖 연결 누락이 가능하다. 전체 기사 검색과 보관은 유지된다.

## 차트와 실패

종목 차트는 현재 거래 세션의 최신 실제 관측 최대 500개이며 전체 장중 틱 이력 보장이 아니다. 90초 초과 구간은 연결하지 않는다. 기사 발행/포털 표시 시각이 차트 범위에 있을 때만 마커를 표시한다. 마커는 기사 시각이며 당시 가격이나 뉴스의 인과 효과가 아니다.

시세 실패, 세션 미확인, 비교 ETF 누락과 관측 부족은 미산정이다. 재시작 후 보관 관측을 재사용한다. 시세 작업자는 기존 요청 풀을 공유하고 토스 인증을 새로 발급하지 않는다. 전체 시장 커버리지, 장기 보존과 기업행동 전체, 사용성·투자 성과는 아직 검증하지 않았다.
