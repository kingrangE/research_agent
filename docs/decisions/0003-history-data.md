# 토스 과거 일봉과 로컬 관측 이력

결정일: 2026-11-16. 이슈 #5. 사용자가 토스증권을 선택하고 인증정보를 로컬 환경에 설정했다. 공식 OpenAPI 1.2.28을 기준으로 구현했다.

## 선택과 대안

| 후보 | 확인한 범위·제약 | 선택 이유 |
|---|---|---|
| 토스 Open API | 국내·미국 일봉, 국내 지수, 종목 마스터·시장 캘린더. OAuth·허용 IP 필요 | 사용자 선택이며 같은 인증으로 양 시장을 검증 가능 |
| KRX Open API | 국내 자료 후보. 별도 인증·서비스 조건 필요 | 미국 자료까지 같은 연결로 해결하지 못해 미연결 |
| Alpha Vantage | 원시 일봉과 별도 수정주가 API. 키·호출 제한·유료 범위 존재 | 사용자 선택과 다르고 국내 확보도 별도여서 미연결 |
| 포털 비공식 차트 | 현재가 연결은 있으나 과거 저장 권한·수정 방식·명세 안정성 미확인 | 기존 현재가 조회를 과거 통계 공급 권한으로 확대하지 않음 |

공식 참고: [토스 명세](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json), [토스 연동 안내](https://openapi.tossinvest.com/openapi-docs/overview.md), [토스 약관](https://home.tossinvest.com/ko/terms/v2?id=752), [KRX](https://openapi.krx.co.kr/), [Alpha Vantage API](https://www.alphavantage.co/documentation/), [Alpha Vantage 약관](https://www.alphavantage.co/terms_of_service/).

토스 약관은 시세를 개인투자자 본인 매매 목적으로 제한하며 제3자 제공·배포·상업 활용을 허용하지 않는다. API 성공은 재배포 권한 확보가 아니다. 이번에는 로컬 개인 검증에 사용하며 장기 보관·외부 서비스 권한은 별도 확인 대상이다. 실제 시세·키·토큰은 저장소에 커밋하지 않는다.

## 구현 계약

- 토큰 발급과 허용한 시장 자료 GET만 사용한다. 주문·계좌 API는 호출하지 않는다. 고정 HTTPS 호스트·리다이렉트 차단을 사용하고 인증정보는 환경변수와 메모리에서만 취급한다. 오류 응답을 그대로 출력하지 않는다.
- 원시 가격과 수정주가는 별도 시리즈다. 수정주가는 취득 시점 제공처 값이며 과거 당시 가용 값이라고 주장하지 않는다. 분할·배당 이력은 미확보다.
- 주식 일봉의 현지 자정 기준을 검증하고 국내 Asia/Seoul·미국 America/New_York로 거래일을 정한다. 종목 ISIN·시장·상장/폐지일은 마스터 원문에 보존하되 현재 마스터가 과거 전체 상태를 뜻하지는 않는다.
- 원문 응답·요청 조건·지문·취득 시각을 저장하고 일봉이 원문을 참조한다. 동일 값 재수집은 마지막 확인만 갱신하며 A→B→A 변경은 세 버전으로 남긴다.
- 일봉에 거래대금이 없으므로 거래량×종가로 만들지 않는다. 과거 거래정지·기업행동·미국 지수 자체는 미확보다. SPY는 ETF 비교 자료이며 지수 자체로 표시하지 않는다.

## 중단·재개와 품질

- 별도 CLI로 수집하고 화면/API 조회에서 외부 시세 요청을 하지 않는다. 기존 Linux Docker 볼륨·SQLite를 재사용해 뉴스 수집과 분리한다.
- 회차별 페이지 예산, 최대 200봉, 서버 커서를 사용한다. 페이지와 다음 위치를 한 트랜잭션으로 저장한다. partial은 같은 명령으로 이어가고 완료 후 재실행은 정정을 대조한다. 진행하지 않는 커서는 오류로 멈춘다.
- 캘린더는 회차당 최대 20개 미확인 날짜를 보충한다. 휴장·개장일 가격 누락·캘린더 미확인을 구분한다. 평일을 임의 개장일로 간주하지 않는다.
- 요청 간 최소 0.4초, 429의 Retry-After를 존중한다. 값이 없으면 로컬 안전 대기 60초를 기록한다. 대기 기한 전 재실행은 요청하지 않는다. 인증/IP 실패를 다른 공급처로 숨기지 않는다.
- 현재·미래 거래일 봉은 미완료 가능 상태다. 누락을 가격·수익률 0으로 채우지 않는다. 실제 반응 수익률 계산은 후속 #11이다.

## 검증·남은 범위

2026-11-06~13의 삼성전자·애플 원시 일봉, 애플 수정 일봉, 코스피, SPY를 실제 API로 취득해 시리즈당 6개 일봉과 요청 구간의 시장 캘린더를 확인했다. 일부 실제 샘플의 성공이며 전 종목·장기 과거·분봉·기업행동의 완전성을 뜻하지 않는다. 정정·재개·커서 정체·휴장/결측·통화/시각/가격 오류는 고정 자료로 검증한다.

토스는 클라이언트당 유효 토큰이 하나이므로 같은 키로 수집 프로세스를 동시에 실행하지 않는다. 장기간 캘린더 정정 탐지·작업 독점·토큰 공유·자동 정기 수집은 후속 #15에서 다룬다. 이 구현의 complete는 지정 구간의 API 순회와 캘린더 보충 완료이며 모든 데이터가 통계적으로 사용 가능하다는 의미가 아니다. 결측·미확보 상태를 함께 확인한다.
